# Skyball Sprint

A mobile-friendly 3D racing game built with Three.js. Play directly in your browser.

- Move with WASD / arrow keys, tap the floor, or use the touch joystick.
- Run to grow your ball. A full ball builds four steps.
- The red player can build in any lane; opponents build only in their own lane.
- After your ball runs out, manually walk back down to grow another.
- Fixed close follow camera, three rounds, and local best times.

Open `index.html` to play offline. No installation or external runtime requests are required.

To rebuild after editing `game.js` or `shell.html`, run `python3 build.py`.
